## 一、必背公式

| 项目 | 公式 / 结论 |
| --- | --- |
| 卷积输出尺寸 | `out = floor((H + 2p - d*(k-1) - 1) / s) + 1`（不能整除向下取整） |
| 卷积参数量 | `k * k * C_in * C_out + C_out`（有偏置时加 C_out） |
| 卷积计算量 | 近似 `H_out * W_out * k^2 * C_in * C_out` |
| 全连接参数量 | `in * out + out` |
| 感受野（逐层） | `r_out = r_in + (k - 1) * j_in`，且 `j_out = j_in * s` |
| 精确率 / 召回率 | `P = TP / (TP + FP)`，`R = TP / (TP + FN)` |
| F1 | `2PR / (P + R)` |
| 信息熵 | `H(S) = -Σ p_c log2 p_c` |
| 信息增益 | `IG = H(D) - Σ (|D_v| / |D|) * H(D_v)` |
| Softmax + 交叉熵梯度 | `∂L/∂z = ŷ - y`（y 为 one-hot） |
| 偏差-方差 | `E[(y - ŷ)^2] = bias^2 + variance + noise` |
| 缩放点积注意力 | `softmax(Q Kᵀ / √d_k) V` |

## 二、机器学习高频考点

**偏差与方差**：模型越复杂，偏差↓ 方差↑；欠拟合是偏差大，过拟合是方差大。Bagging 主要降方差，Boosting 主要降偏差。

**正则化**：L1（Lasso）产生稀疏解、可做特征选择；L2（Ridge）让权重整体收缩、更平滑。λ 越大正则越强，过拟合缓解但可能欠拟合。

**评估**：准确率在类别不平衡时会被多数类主导；精确率关注"报出来的对不对"，召回率关注"该找的找到没有"；ROC/AUC 只看排序，对阈值和类别比例不敏感。交叉验证（K 折）用于在小数据上稳定评估。

**决策树**：ID3 用信息增益（偏向取值多的特征），C4.5 用信息增益率，CART 用基尼指数（可回归）。剪枝防过拟合。

**集成**：随机森林 = Bagging + 随机特征（降方差）；GBDT = 串行拟合负梯度（残差），XGBoost 用二阶泰勒展开并加正则项，LightGBM 用直方图 + leaf-wise。

**SVM**：最大化间隔；软间隔引入松弛变量和惩罚 C，C 越大越容易过拟合；核技巧把低维不可分映射到高维（RBF 核最常用）。

**聚类与降维**：K-means 需指定 K、对初值和异常值敏感、只能得到凸簇，需多次初始化（K-means++）；DBSCAN 基于密度、能识别噪声；PCA 是无监督线性降维（按方差最大方向），LDA 是有监督（按类间/类内散度比）。

**特征工程**：标准化（zero-mean/unit-variance）适合梯度类与距离类模型；归一化到 [0,1] 适合有界输入；类别特征用独热/目标编码；缺失值可填充或加缺失指示。

## 三、深度学习高频考点

**激活函数**：sigmoid 输出 (0,1)、两侧饱和导致梯度消失，输出非零均值；tanh 零均值但仍饱和；ReLU 计算快、缓解梯度消失，但负半轴梯度为 0 可能"神经元死亡"；LeakyReLU/GELU 是常见改良。

**初始化**：不能全零（对称性破坏不了）；Xavier 适合 tanh/sigmoid（方差约 1/fan_avg），He 适合 ReLU（方差 2/fan_in）。

**归一化**：BN 沿 batch 维对每个通道归一化，训练时用当前 batch 的均值方差、推理时用滑动平均；LN 沿特征维归一化、与 batch 无关，适合变长序列和 Transformer；GN 按通道分组，适合小 batch。

**优化器**：SGD 只看当前梯度；Momentum 累积历史梯度抑制震荡；AdaGrad 累积平方梯度使学习率单调衰减；RMSProp 用滑动平均修正；Adam = 一阶矩 + 二阶矩 + 偏差校正，AdamW 把权重衰减与梯度解耦。

**正则化手段**：Dropout（训练随机置零，推理关闭并保持期望不变）、权重衰减、早停、数据增强、标签平滑、小模型/共享参数。梯度爆炸用梯度裁剪，梯度消失用残差连接/合理初始化/换激活函数。

**卷积**：1×1 卷积做通道线性组合（升降维、跨通道信息融合）；池化无可学习参数，最大池化保留显著特征；空洞卷积扩大感受野不增参数；depthwise separable 卷积把空间卷积和通道卷积拆开以降低计算量。

**序列与注意力**：RNN 长依赖会梯度消失/爆炸，LSTM 用遗忘门、输入门、输出门 + 细胞状态缓解；GRU 简化为更新门和重置门。自注意力复杂度 O(n²d)，n 是序列长度；多头注意力在不同子空间并行计算；Transformer 需要位置编码补顺序信息；除以 √d_k 是为了防止点积过大让 softmax 进入饱和区、梯度变小。

**训练技巧**：warmup 让初期参数远离最优时不用大学习率；学习率衰减（cosine/step）帮助收敛；batch 变大时可适当调大 lr；混合精度训练用 fp16/bf16 省显存。

## 五、易错点速记

- 卷积输出向下取整，`224, k=7, s=2, p=3 → 112`；`k=3, s=2, p=1, 32 → 16`。
- 参数量别忘了乘 `k*k`，也别忘了偏置是 `C_out` 个而不是一个。
- 精确率、召回率的分母不同：P 除 `TP+FP`，R 除 `TP+FN`。
- 信息熵用 log2 时单位是 bit；信息增益一定 ≥ 0。
- 类别不平衡看 F1、AUC、召回率，别只报准确率。
- BN 推理不能用当前 batch 统计量；Dropout 推理必须关闭。
- Dropout、数据增强、早停、L2 都是正则化；增大模型不是。
- 注意力里除的是 `√d_k`，不是 `d_k`。
- 全零初始化会让同一层神经元对称、学不到不同特征。
