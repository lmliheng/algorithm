## 本地自测

```bash
python 字符串解码.py < in.txt
```

或直接在 VS Code 里把输入粘贴到终端（`Ctrl+Z` 回车结束输入），或在调试配置里用重定向。

题面里的示例输出都已核对过，可当作第一组自测数据。
