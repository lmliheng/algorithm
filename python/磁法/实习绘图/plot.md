异常体标注

向上延拓（Upward Continuation）

原理：数学上将观测面"抬高"一定高度，计算高处的磁场
作用：压制浅部高频干扰，突出深部大尺度异常体
你看到的：延拓后等值线变得更平滑，小异常消失，大异常更清晰 → 判断异常体是深部还是浅部

2. 垂向一阶导数（∂ΔT/∂z）

原理：对网格化数据在垂直方向求导
作用：锐化异常，使异常体边界更清晰
你看到的：导数图上零值线大致对应磁性体边界 → 圈定异常体范围

3. 剖面曲线图

原理：每条测线的 ΔT 沿距离画曲线
作用：直观展示每条测线的异常形态（峰值位置、宽度、对称性）
你看到的：曲线峰值偏移说明斜磁化，双峰说明多个异常体

4. 化极处理（RTP） — 把斜磁化下的异常转换为垂直磁化下的异常，使正异常中心对准磁性体正上方。需要知道当地磁倾角和偏角。
